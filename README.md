# Kamaldeen's Portfolio

A small, static portfolio site built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `new_update.html` in a browser, or serve this folder with a local static web server. Keep `styles.css`, `script.js`, `portrait.jpeg`, `favicon.svg`, and `site.webmanifest` beside the HTML file so their relative paths resolve.

## Before publishing

Replace project cards' self-links with real repository or live-demo URLs when available. Add only verifiable project details, credentials, employment history, and dates. Add a GitHub link once the profile URL is known. The current social preview uses `portrait.jpeg`; provide a dedicated wide image if a tailored preview is desired.

## Portfolio content updates

The Projects section currently describes work represented by this site; project repository/demo links can be added once real URLs exist. The Résumé & Credentials section lists supplied education and learning context and intentionally does not link to a missing résumé file.


## Add project files

Each project card opens a detail page in its own folder under projects/. Add screenshots, source code, or demo files to the matching folder, then edit that folder's index.html to link or display the files. Read the folder-level README.md for the steps. Update the matching project card in 
ew_update.html when its details or links change.


## Add a project

Start with ADD_A_PROJECT.md, which includes a copy-ready card snippet and the local folder workflow. Duplicate projects/_template/ for each project detail page.
